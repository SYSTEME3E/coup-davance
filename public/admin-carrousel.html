Images du carrousel

Ces images s’affichent en haut du dashboard, sous l’en-tête. Une seule image reste fixe ; à partir de 2 images, elles défilent toutes les 5 secondes. Format large conseillé (1200 × 525). 10 images maximum.

Code du jour

Choisis la plateforme (1Win, 1xBet, Melbet…) puis colle le code que tu as préparé sur son site. Il s’affiche sur le dashboard, juste après les bonus partenaires, pendant 24 h. Un nouveau code pour la même plateforme remplace l’ancien.
